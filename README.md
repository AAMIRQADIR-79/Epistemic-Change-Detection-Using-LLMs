# Bibliometric Analysis for Scientific Publications Using Large Language Models (LLMs)

This repository contains the complete workflow for a bibliometric analysis and systematic literature review aimed at identifying epistemic change in scientific publications using Large Language Models (LLMs).

## Project Overview
The project integrates bibliometric techniques, PRISMA-based literature screening, Python and R programming, and data visualization to analyze publication trends, citation patterns, research themes, and emerging knowledge structures in LLM-related research.

## Repository Contents
- Search strategies for multiple academic databases
- PRISMA methodology and screening process
- Python scripts for data preprocessing and analysis
- R scripts using Bibliometrix/Biblioshiny
- Web of Science and other bibliographic datasets
- Data cleaning and deduplication workflows
- Bibliometric visualizations and network analysis
- Literature review and supporting documentation

## Tools & Technologies
- Python
- R (Bibliometrix & Biblioshiny)
- Microsoft Excel
- Web of Science
- Scopus
- ACM Digital Library
- SpringerLink
- Wiley Online Library

## Research Objectives
- Identify research trends and emerging topics
- Analyze citation, collaboration, and keyword networks
- Explore epistemic changes in scientific publications
- Evaluate the impact of Large Language Models on scholarly research
